# 整轨翻译任务与持久译文

日期：2026-10-09。状态：0.2.0 已采用。

用户选择在纯 Firefox 扩展中借鉴 yt-dlp 的整轨字幕获取逻辑，并将一个源语言轨道的完整字幕通常交给一次 OpenAI 兼容 API 请求翻译，只有文字实在过长时例外。完成的译文持久保存，可按源时间轴播放，并导出原文、译文或双语 SRT。

翻译任务不再随播放位置分批推进；用户切换视频或关闭标签页后，已提交的任务继续在扩展后台完成并保存。这样能在翻译完成后复用全片译文，但首次等待和单次请求的输入、输出要求会提高；后台任务的存续也需要与页面的显示状态分开处理。

Firefox 退出后扩展无法继续运行。完整结果需要通过逐条校验后才保存为已完成译文，不能把截断或缺失条目的响应当作完成。现有 ADR 0001 描述的字幕响应捕获可继续作为获取来源，但播放位置调度与实时文本翻译回退需依据整轨目标调整。

Firefox 使用 Manifest V2 的持久后台脚本，让已提交的长请求独立于视频标签页存续。Manifest V3 的后台可在闲置时卸载，无法仅凭页面轮询保证关闭标签页后的长任务。该选择增加后台常驻开销，换取此版本明确要求的后台继续行为；若后续迁移 Manifest V3，需要重新验证任务生命周期。[Firefox 后台脚本文档](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Background_scripts)
