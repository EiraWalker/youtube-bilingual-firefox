# 0004：以观看需求限制翻译，字幕文件只按明确操作保存

日期：2026-10-15。状态：0.4.0 已采用。依据：[规格](../spec-demand-driven-subtitles-and-explicit-cache.md)、Issue #7 及随后用户的实现授权。

保留整轨源获取、分段翻译、每视频最多三个在途请求、跳转保留在途结果和原字幕回退；取代 ADR 0002/0003 中跨页面持续补译全轨、默认持久保存、落盘后才公开译文的选择。

后台统一拥有观看需求和请求资格。内容脚本上报页面会话、单调序号、视图代次、当前位置及有效观看状态；异步启动前先记录状态，避免源加载期间发生的暂停被迟到启动覆盖。每个页面独立持有 10 秒租约，正常每 2.5 秒更新；暂停、隐藏、导航、关闭显示、结束及广告立即撤销需求。标签页生命周期事件补充清理，过期需求不能提交新请求。

新增翻译只选取当前位置与前方 120 个源视频秒相交的完整字幕条目；缓冲低于 60 秒再补充至上限。所有并发片段共用窗口，不回绕补译跳过内容。重试同样检查观看资格和范围。在途请求可返回并合并内存，但不能使失效需求复活。倍速影响批量大小，不能扩大窗口。

普通字幕及译文只存在扩展后台内存，页面切换可复用，浏览器退出后不恢复。旧版内部缓存只读兼容，原有主动清除完整旧缓存操作继续保留。新版本设置项仍持久保存。

“缓存字幕”是显式快照：复制当时已有结果，写入用户配置目录，不补译全轨，也不使后续响应自动落盘。结构缓存与原文 SRT、部分或完整双语 SRT 一起发布。后台内存不依赖磁盘写入成功，文件操作失败不丢失已收到译文。

Firefox downloads 接口只能指定下载目录内的相对路径，无法实现任意绝对目录和通用回读。本期选择 Windows Native Messaging 组件读写自定义目录，随包提供 Python 标准库实现及当前用户安装/卸载脚本。普通翻译不依赖组件，只有配置目录、读取已有缓存及主动保存需要本地通信。

组件按稳定身份目录存放文件，以原子替换 `current.json` 发布一份完整修订。先校验并合并已有有效条目，再生成结构文件和 SRT；失败保留旧修订。传输分块并校验 SHA256，防止单条本地消息大小截断长字幕。目录中的结构文件是重启后复用的来源，不要求扩展保存字幕索引。

代价是增加本地组件交付、受限文件协议和目录配置的维护成本，Windows 用户需自行安装缓存组件；收益是字幕缓存位置真实可控，文件可直接获取和回读，普通观看不会产生全片翻译或默认字幕落盘。

验证入口沿用后台字幕任务服务和播放器消息契约，另通过真实宿主进程及隔离 Firefox 验证文件读写、停止提交和浏览器重启回读。参见 [0.4.0 验证记录](../validation-0.4.md)。
