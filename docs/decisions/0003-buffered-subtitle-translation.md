# 0003：分段保存译文并按视频独立调度

日期：2026-10-10。状态：0.3.0 已采用。

为减少整轨翻译造成的首批等待，保留完整源轨道获取，但将译文按字幕翻译段校验、保存和公开；播放器按条目可用性显示双语，不再等待整轨完成。每视频独立最多三个在途请求，跳转只改变未发送内容的优先级，已发送请求继续返回和保存，跨视频后台任务继续运行。

这取代 ADR 0002 中与整轨单请求、整轨完成后才公开结果有关的选择，保留缓存、后台完成及完整 SRT 导出目标。代价是维护部分完成状态、并发结果合并与可恢复片段；首段采用 30 秒/600 字符上限，另两个启动段 60 秒/1,200 字符，常规段 180 秒/6,000 字符，缓冲充足时 300 秒/6,000 字符，并根据请求耗时和播放倍速选择。

临时失败额外自动重试两次，诊断仅写控制台。Firefox 重启不自动收费，重新开启或恢复后只补缺失部分。已保存译文先串行合并和持久化再公开，避免并发覆盖；旧完整缓存继续兼容。

详见 [PRD](../prd-buffered-subtitle-translation.md)。
