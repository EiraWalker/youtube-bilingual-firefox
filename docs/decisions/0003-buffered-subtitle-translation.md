# 0003：分段保存译文并按视频独立调度

日期：2026-10-10。状态：拟实施；核心产品行为已确认，参数待实测。

为减少整轨翻译造成的首批等待，保留完整源轨道获取，但将译文按字幕翻译段校验、保存和公开；播放器按条目可用性显示双语，不再等待整轨完成。每视频独立最多三个在途请求，跳转只改变未发送内容的优先级，已发送请求继续返回和保存，跨视频后台任务继续运行。

这将取代 ADR 0002 中与整轨单请求、整轨完成后才公开结果有关的选择，保留缓存、后台完成及完整 SRT 导出目标；当前 0.2.3 实现尚未改变。代价是需要维护部分完成状态、并发结果合并与可恢复片段；首批小段和后续大段的参数通过测量决定。

详见 [PRD](../prd-buffered-subtitle-translation.md)。
