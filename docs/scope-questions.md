# 首版范围与后续决策

更新时间：2026-10-09。

## 用户已确认

- 创建本地目录，参考沉浸式翻译的官方功能逐步实现。
- 首版实现 YouTube 双语字幕，嵌入 YouTube 播放器。
- 使用 OpenAI 兼容 API 翻译字幕。
- 第一目标浏览器为 Firefox。

## 当前实现默认值

以下是可调整的实现选择，不属于用户额外确认的需求：

- 默认目标语言为简体中文（`zh-CN`），可在设置中修改。
- 默认手动启用；提供自动启用选项。
- API 地址、模型和 Key 由设置页填写；未预设模型或个人密钥。
- 已有人工或自动生成字幕为源；无法获取完整时间轴时使用播放器文本回退。
- 原文在上、译文在下；字体大小和底部距离可调。
- 以临时扩展交付，尚未申请 Mozilla 签名。

## 验收范围

```text
Firefox 首版
├─ API 配置 → 保存网站权限 → 测试连接
├─ YouTube 已有字幕 → 分批翻译 → 播放器双语显示
│  ├─ 暂停 / 倍速 / 前后跳转 / 全屏
│  ├─ 切换字幕语言 / 切换视频
│  └─ 接口错误提示 / 明确重试
└─ 完整字幕获取失败 → 播放器实时字幕回退
```

## 后续决策树

```text
首版真实使用反馈
├─ 用户 API / 模型验收 [真实调用及本地 Firefox 播放器通过]

├─ 字幕获取与延迟优化 [按反馈决定]
```

官方功能调查中的其他 F01–F33 能力尚未纳入首版。领域术语记录在 CONTEXT.md；需求与默认选择记录在本文件；字幕获取取舍记录在 ADR 0001。

0.2.0 的完整需求见[整轨翻译规格](whole-track-alignment.md)与[ADR 0002](decisions/0002-whole-track-background-translation.md)。本文件前面的“当前实现默认值”与“验收范围”记录 0.1.0；0.2.0 已改为整轨翻译、后台独立任务、持久译文与 SRT 导出。
